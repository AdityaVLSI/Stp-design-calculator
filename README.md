# STP Design Calculator

An open-source wastewater engineering tool for designing and sizing key units of a Sewage Treatment Plant (STP). This project automates engineering calculations used in wastewater treatment design, helping engineers, students, and researchers perform quick and reliable preliminary sizing of treatment units.

## Overview

The STP Design Calculator is developed to simplify the design process of wastewater treatment plants by providing automated calculations for major process units. The tool follows commonly used wastewater engineering design practices and can be expanded to support multiple treatment technologies.

## Features

- Equalization Tank Design
- Aeration Tank Sizing
- Clarifier Design
- Tube Settler Design
- MBBR Media Volume Calculation
- UASB Reactor Sizing
- Air Blower Selection
- Pump Capacity Calculation
- Sludge Generation Estimation
- Hydraulic Retention Time (HRT) Calculation
- Organic Loading Rate (OLR) Calculation
- Design Report Generation

## Treatment Technologies Covered

- Activated Sludge Process (ASP)
- Moving Bed Biofilm Reactor (MBBR)
- Sequencing Batch Reactor (SBR)
- Membrane Bioreactor (MBR)
- Upflow Anaerobic Sludge Blanket Reactor (UASB)
- Tube Settler Systems
- Water Softening Systems
